# Build
> Fire the prompt. Open in browser. Iterate once. Ship.

## scenario

Your prompt is validated. Open Claude.ai in a new tab. Keep this platform tab open alongside it — you will need the done criteria below.

Target: a working proposal microsite in the browser within 10 minutes. Use any remaining time to iterate.

## do_this

**Round 1 — First build:**
1. Paste your full prompt into Claude.ai
2. When Claude responds, copy the entire HTML code block
3. Save as `proposal.html` on your desktop and double-click to open in a browser
4. Check it against `screenshot_1.png` and `screenshot_2.png` — does it match the visual standard?

**Round 2 — One targeted iteration:**
Identify the single most important gap — usually it is a stakeholder section that is too generic or the ROI hero that does not stand out enough. Write one follow-up instruction that fixes only that gap. Fire it in the same Claude conversation — do not start a new chat.

**If time permits — further refinements:**
Ask Claude to: make the tab strip sticky so it stays at the top while scrolling, add a hover effect to the case study cards, or make the ROI bar chart animate on first scroll-into-view.
